# Tu repositorio de marca

Esta carpeta es una plantilla mínima, sin recursos privados. Crea tu propio repositorio en GitHub (preferiblemente privado) y copia `brand/brand.yaml` a esa misma ruta. Edita `brand.name` y guarda.

No necesitas copiar el código de AVIA Social, hacer un fork de BrightBean ni acceder a las marcas privadas del mantenedor. El repositorio público `joacoAviles/avia-social` es la aplicación; tu repositorio de marca es su fuente de identidad opcional.

Sigue [la guía de conexión](../../docs/ONBOARDING.md#github-paso-a-paso) para crear un token de lectura. No guardes tokens ni secretos en archivos versionados. La vinculación comprueba acceso; sincronización y aprobación son pasos separados.
