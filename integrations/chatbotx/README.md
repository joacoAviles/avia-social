# Extensión futura ChatbotX
No se incluye ni se afirma interoperabilidad probada con ChatbotX.
Límite de integración: proceso separado, credencial API por workspace, webhooks firmados,
IDs de eventos para deduplicación, colas persistentes y aprobación humana antes de cualquier envío.
No compartir cookies, base de datos ni tokens sociales. Auditar licencia de la edición concreta,
contratos API y permisos Meta antes de habilitar. El repositorio solo define este contrato de extensión.
