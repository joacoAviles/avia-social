Prepara Calendar una vez

  1. Abre Google Cloud. Selecciona el proyecto de tu aplicación AVIA. Puedes usar el mismo proyecto de YouTube, sin borrar sus credenciales.
  2. En APIs y servicios → Biblioteca habilita Google Calendar API.
  3. En Google Auth Platform → Audience (Público), si estás en Testing, añade como Test user el correo con el que vas a conectar el calendario. Debe ser el proyecto del cliente OAuth que guardarás aquí.
  4. En Data Access configura los permisos de lectura de lista de calendarios y eventos: calendar.calendarlist.readonly y calendar.events.readonly.
  5. En Clients (Clientes), crea un cliente de tipo Aplicación web o añade esta URI a tu cliente existente. Conserva las URI de YouTube y las demás conexiones.
{{ calendar_callback }}

Si usas el túnel a PROD01, mantén abierto SSH y completa el acceso en el mismo navegador usando el mismo puerto localhost. Para acceso permanente configura el dominio HTTPS de tu instalación.

{% csrf_token %}

Después pulsa Conectar Google Calendar, acepta los permisos de lectura y selecciona el calendario. Los eventos serán visibles solo para tu usuario en este espacio. No creamos ni modificamos eventos en Google.

Si Google muestra 403 access_denied y menciona testers, revisa Audience → Test users. Comprueba que el Client ID del error coincida con Clients en ese proyecto. No cambies a producción solo para saltar ese error. En Testing, los permisos offline pueden exigir reconectar después de 7 días.
