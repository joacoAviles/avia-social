Dominio HTTPS con Cloudflare · configuración inicial

Para registrar el retorno en Meta necesitas una dirección pública estable, como https://social.tudominio.cl. Cada instalación usa su propio dominio y cuenta de Cloudflare.

  1. Añade tu dominio a Cloudflare y completa su activación. En Cloudflare One, abre Networks → Tunnels (o Connectors) y crea un túnel Cloudflared llamado «AVIA Social». Elige Docker.
  2. Copia únicamente el token mostrado después de --token. No lo pegues en este chat ni en GitHub.
  3. En Published application routes, elige tu subdominio «social», tu dominio y servicio HTTP → app:8000. Deja HTTP Host Header sin modificar. Activa Always Use HTTPS para ese hostname y no apliques caché a las páginas de AVIA.
  4. En el servidor, dentro de la carpeta avia-social, ejecuta python3 scripts/cloudflare_setup.py. Introduce tu dominio y el token cuando lo pida. Después ejecuta docker compose up -d --build --wait app worker cloudflared.
  5. Abre el dominio HTTPS, inicia sesión y vuelve a esta guía. Copia la dirección de retorno de cada proveedor en Meta o Google. Conserva las credenciales existentes; no reinstales ni elimines los volúmenes.

El asistente prepara la instalación; no crea el dominio ni los registros de Cloudflare automáticamente. El túnel resuelve la dirección HTTPS, pero no sustituye los permisos y la revisión de Meta ni añade soporte para Unified Login.
