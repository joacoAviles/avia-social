1 · Elige el repositorio de tu marca

Para instalar la aplicación se clona joacoAviles/avia-social. No necesitas un token para clonar ese repositorio público.

Para tu identidad usa otro repositorio, preferiblemente privado. Si partes de cero, crea uno en GitHub → New repository y copia el archivo de la plantilla de marca, conservando la ruta brand/brand.yaml. Cambia «Mi marca» por tu nombre y guarda el archivo. No necesitas clonar BrightBean ni los repositorios privados de AVIA.

2 · Crea un token de lectura

  1. En GitHub abre tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Escribe un nombre como «AVIA Social», elige una caducidad y en Resource owner selecciona al dueño del repositorio.
  3. En Repository access elige Only select repositories y selecciona únicamente tu repositorio de marca.
  4. En Repository permissions, establece Contents en Read-only. No concedas escritura. GitHub incluye Metadata de lectura.
  5. Pulsa Generate token y cópialo al campo de abajo. Si tu organización exige aprobación, espera a que lo apruebe antes de verificar.

3 · Vincula y revisa

En «Repositorio» escribe tu-usuario/tu-marca, no la URL completa ni el repositorio de la aplicación. Guarda el token solo en el formulario. Después abre el catálogo, sincroniza y revisa los recursos antes de aprobarlos. Vincular el repositorio no cambia por sí solo la apariencia de AVIA Social.
