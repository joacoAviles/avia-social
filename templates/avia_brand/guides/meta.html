{% if card.platform == 'instagram_unified' %}

1 · Prepara la app una sola vez

  1. Meta → Casos de uso → Administrar mensajes y contenido en Instagram → Configuración de la API con inicio de sesión unificado.
  2. Selecciona una configuración compatible con Instagram y token empresarial SUAT. Copia su Configuration ID. Para publicar incluye instagram_basic e instagram_content_publish; conserva los permisos obligatorios que indique Meta.
  3. Registra exactamente el callback HTTPS de abajo. Es distinto al callback de Instagram directo.
  4. Guarda aquí el Meta App ID, su secreto y Configuration ID. Selecciona Unified Login en el formulario.

2 · Inicia sesión y elige tus cuentas

Pulsa Conectar, elige Instagram o Facebook en Meta, selecciona el portfolio y autoriza las cuentas profesionales. Al regresar marca una o varias cuentas. Puedes añadir otras después sin borrar las anteriores.

En desarrollo usa tu cuenta profesional invitada como evaluadora y acepta la invitación en Instagram. Para clientes externos se requiere el acceso avanzado y modo activo que Meta solicite.

Esta versión incorpora autorización y publicación. Mensajes, webhooks y métricas del flujo nuevo siguen pendientes de validación; no se activan al conectar. Si Meta revoca el token o vence, vuelve a autorizar el portfolio.

{% elif card.platform == 'instagram_login' %}

1 · Prepara Instagram directo

Necesitas una cuenta profesional de Instagram (empresa o creador). No necesitas una página de Facebook ni conectar otra red a AVIA.

  1. Si tu cuenta es personal, cambia a una cuenta profesional desde los ajustes de Instagram.
  2. El administrador entra en Meta for Developers → Mis aplicaciones y crea o selecciona la aplicación. La cuenta de desarrollador de Meta es una configuración administrativa; no vincula una página de Facebook a tu Instagram.
  3. Solo si Meta permite el flujo anterior, configura Instagram API con Instagram Login. Si indica que no está disponible para apps nuevas y exige Unified Login, selecciona «Instagram · inicio de sesión unificado» en AVIA; no intercambies App IDs en el conector anterior.
  4. Registra la dirección de retorno que mostramos debajo. Usa el dominio HTTPS de esta instalación.
  5. Copia el Instagram App ID y su secreto correspondiente a este formulario y guarda. No uses las credenciales de otra aplicación ni tokens copiados de Instagram.

2 · Conecta Instagram

Pulsa «Conectar Instagram directo», inicia sesión en Instagram y acepta los permisos. Al regresar revisa el nombre y el estado de la cuenta. Para otra cuenta, vuelve a «Añadir otra cuenta» y elige esa cuenta en Instagram. Si el proveedor recuerda la anterior, cambia la sesión en Instagram antes de autorizar. No se reemplazan cuentas con identificadores distintos. No hace falta completar Facebook, Google ni GitHub primero.

{% elif card.platform == 'instagram' %}

1 · Prepara Instagram vía Facebook

Para aplicaciones que ya admiten Facebook Login con token de usuario. Cada Instagram debe ser profesional y estar vinculado a una página que administras. No es el flujo Unified Login/SUAT de las apps nuevas.

  1. En Meta, habilita el acceso a Instagram y a las páginas vinculadas para tu aplicación existente.
  2. Registra exactamente el callback mostrado debajo. Este callback es distinto al de Instagram directo.
  3. Guarda el App ID y secreto de Meta; si corresponde, el Configuration ID de una configuración con token de usuario.

2 · Elige todas tus cuentas

Inicia sesión con Facebook y autoriza las páginas vinculadas. AVIA mostrará las cuentas de Instagram disponibles: marca una o varias y confirma. Puedes repetir «Añadir otra cuenta» con otra autorización; las cuentas anteriores permanecen.

{% else %}

1 · Prepara Facebook Pages

Conecta páginas sobre las que tienes permisos de administración. Esta opción no publica en perfiles personales ni ofrece conexión de grupos.

  1. El administrador abre Meta for Developers → Mis aplicaciones y crea o selecciona la aplicación.
  2. Configura el inicio de sesión de Facebook y el acceso a páginas para las funciones que usarás. El conector actual usa un token de usuario para descubrir páginas. Si usas Login for Business, copia su Configuration ID (config_id) al formulario. No selecciones SUAT para este flujo.
  3. Registra la dirección de retorno que aparece debajo en la configuración OAuth. Debe coincidir exactamente con tu instalación HTTPS.
  4. Copia el App ID y App Secret desde Configuración de la app → Básica. El config_id pertenece a Login for Business → Configuraciones, y no es el App ID. Guarda aquí los tres valores cuando corresponda.

2 · Selecciona tus páginas

Pulsa «Conectar Facebook», inicia sesión y concede acceso a las páginas que quieras usar. Completa la selección que muestre el flujo y revisa las cuentas registradas al volver. No necesitas conectar Instagram primero.

{% endif %}

El administrador prepara la aplicación una vez; cada usuario autoriza su cuenta. Para pruebas usa cuentas y roles autorizados por Meta. Para usuarios externos, completa la revisión y los requisitos de acceso que Meta solicite para los permisos elegidos. Una autorización no confirma que todas las funciones de publicación o mensajes estén aprobadas.

Qué revisar antes de autorizar

  1. Meta App ID, secreto y config_id deben pertenecer a la misma app y configuración.
  2. La cuenta de prueba debe tener los roles y acceso a los activos requeridos. Revisa solicitudes pendientes del portafolio.
  3. Publicar en páginas requiere permisos como pages_manage_posts; listar páginas, pages_show_list. No añadas permisos publicitarios solo porque la pantalla los ofrece.
  4. La URL OAuth es para iniciar sesión. La URL de webhook es otra configuración: no pegues el callback OAuth en webhooks.
  5. Una conexión guardada no acredita revisión de Meta, mensajes ni publicación real. Comprueba esas funciones por separado.

Facebook personal

Tu perfil personal sirve para iniciar sesión y autorizar las páginas que administras. No es un canal de publicación automática: AVIA no ofrece programación sobre el perfil personal. Puedes preparar contenido en AVIA y publicarlo manualmente en Facebook.

Si falta una cuenta

  1. Comprueba que entraste con la persona que administra esa página o Instagram.
  2. En el diálogo de Meta revisa los activos autorizados; solo aparecerán los que concediste.
  3. En modo de desarrollo, la persona y sus activos deben estar habilitados para pruebas de esa app.
  4. Para una app nueva que solo ofrece Unified Login/SUAT, elige el conector de inicio de sesión unificado. No cambies las credenciales de una conexión anterior para intentar migrarla.
