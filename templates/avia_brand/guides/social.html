1 · Prepara la aplicación (administrador)

  1. Abre TikTok for Developers, inicia sesión y entra en Manage apps. Crea o selecciona tu aplicación.
  2. Configura su sitio web y la información solicitada por TikTok. Añade Login Kit para Web y los productos/permisos que vaya a usar tu aplicación; iniciar sesión no concede automáticamente permiso para publicar.
  3. En Login Kit registra la dirección de retorno que aparece debajo. Debe ser una dirección HTTPS de tu instalación y coincidir exactamente.
  4. En Credentials copia Client key y Client secret a este formulario. Guarda. Usa el entorno y las cuentas de prueba autorizadas por TikTok; para producción completa la revisión que solicite el proveedor.

1 · Prepara la aplicación (administrador)

  1. Abre Google Cloud Console y crea o selecciona un proyecto.
  2. En APIs & Services → Library habilita YouTube Data API v3.
  3. Configura Google Auth Platform: Branding, Audience y Data Access. Si estás en modo de prueba, añade la cuenta que autorizarás como usuario de prueba.
  4. En Clients crea un cliente OAuth de tipo Web application. Añade la dirección de retorno de abajo en Authorized redirect URIs, exactamente como aparece.
  5. Copia Client ID y Client secret aquí y guarda. Completa la verificación que Google solicite para los permisos y el uso previsto.

2 · Conecta tu cuenta (usuario)

Después de guardar, pulsa «Conectar {{ card.title }}», inicia sesión en el proveedor, elige la cuenta y acepta los permisos. No copies tokens de usuario manualmente. Al regresar, revisa el nombre y el estado de la cuenta. Puedes repetir la autorización para añadir otra cuenta; no necesitas crear una aplicación nueva para cada cuenta.
