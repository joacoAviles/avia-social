1 · Crear o revisar la app en Meta (una vez)
  1. Entra a developers.facebook.com/apps ↗ → Crear app → «Otro» → tipo Empresa (o abre la tuya).
  2. Casos de uso → Agregar:
    • «Administrar todo en tu página» → Personalizar → pulsa Agregar en pages_show_list, pages_manage_posts, pages_manage_engagement, pages_read_engagement, pages_read_user_content, read_insights, business_management{% if meta.inbox_enabled %}, pages_manage_metadata{% endif %}.
    • «Administrar mensajes y contenido en Instagram» → Configuración de la API con inicio de sesión de Facebook → agrega instagram_basic, instagram_content_publish, instagram_manage_comments, instagram_manage_insights{% if meta.inbox_enabled %}, instagram_manage_messages{% endif %}.
    • Opcional, Instagram directo: en el mismo caso de uso → Configuración de la API con inicio de sesión de Instagram → copia el ID de la app de Instagram y su secreto.
      • {% if meta.inbox_enabled %}
    • Bandeja de Messenger: agrega «Interactuar con clientes en Messenger» y pages_messaging.
      • {% endif %}
  3. Configuración de la app → Básica: completa Dominios de la app con {{ meta.origin }}, Política de privacidad {{ meta.origin }}/privacy/, Términos {{ meta.origin }}/terms/. Copia App ID y App Secret.
  4. Inicio de sesión con Facebook → Configuración: activa «Inicio de sesión con OAuth web» y «Forzar HTTPS», y pega en URI de redireccionamiento de OAuth válidos estas dos líneas exactas: {{ meta.callbacks.facebook }} {{ meta.callbacks.instagram }}
  5. Instagram directo → Configuración de inicio de sesión para empresas → URI de redireccionamiento: {{ meta.callbacks.instagram_login }}
  6. Roles de la app: mientras la app esté en modo desarrollo, solo pueden conectar personas con rol. Agrega tu Facebook como Administrador/Tester y, para Instagram directo, tu cuenta como Instagram Tester (acepta en Instagram → Configuración → Apps y sitios web → Invitaciones de evaluador).
  7. Tu Instagram debe ser profesional (Empresa o Creador). Para «Instagram vía Facebook», además vinculado a una página que administras.
