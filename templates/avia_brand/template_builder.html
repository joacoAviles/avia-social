Qué incluye

Identidad, dos colores, tipografías declaradas, tono, audiencia, temas de contenido, tres ejemplos de publicaciones, carpeta de recursos e instrucciones. Los ejemplos requieren revisión; no son publicaciones listas para enviar.

Cómo subirlo

  1. Descomprime el ZIP.
  2. En GitHub abre tu repositorio privado → Code → Add file → Upload files.
  3. Sube brand/ y assets/ a la raíz; debe existir brand/brand.yaml. Si hay archivos anteriores, revisa antes de reemplazarlos.
  4. Confirma los cambios y vuelve a AVIA → Catálogo → Sincronizar → Revisar y aprobar.

No se incluyen logos oficiales, archivos de tipografías ni claves. La aplicación actual usa nombre y colores; el resto queda organizado en el catálogo para su uso posterior.
